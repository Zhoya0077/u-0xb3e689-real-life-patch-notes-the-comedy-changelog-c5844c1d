Write the funniest one-line patch note for a bug in real life or human biology, 160 characters max. Free entry, open 72 hours, and the top 5 places split the reward pool equally.

## Run it

```sh
node main.ts
```

The program writes one line (124 characters, no trailing newline) to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`): a release note for
the bug where a 12-second jingle loops in the brain for 6 hours with no
skip button, no mute, and no uninstall.
